# SimplePDFReader

قارئ PDF خفيف للأجهزة الضعيفة (Android 7+) مع تمييز ذكي للسطور.

## المميزات
- **تمييز ذكي بدون OCR**: بيكتشف حدود السطور من الصورة نفسها، فالتمييز بيطلع مستقيم حتى في الكتب الممسوحة ضوئياً.
- **فرشاة** بخطوط مستقيمة، وممحاة، وتراجع، و8 ألوان مع تحكم في الشفافية.
- **الصفحات والفهرس**: شبكة مصغّرات + فهرس مرتب، مع فلاتر (رئيسي / جانبي / مرجعي / مهمة / بتعليق).
- **وسم الصفحات**: عنوان رئيسي، عنوان جانبي، صفحة مرجعية، مهمة ★ (ممكن أكتر من وسم للصفحة).
- **اسم وتعليق لكل صفحة**، وبحث فيهم وفي الوسوم وأرقام الصفحات.
- وضع ليلي وأبيض وأسود، وتذكّر آخر صفحة لكل كتاب، وقائمة آخر الملفات.

## التجميع
أي push على أي فرع بيشغّل GitHub Actions ويطلّع `SimplePDFReader-debug` (ملف APK) في تبويب Actions ← Artifacts.
